# Joom - Video Conferencing Application

Version 2.0

## Overview

Joom is a video conferencing application built with modern web technologies. It allows users to create and join virtual meeting rooms, communicate via video, audio, and text chat in real-time.

## Features

- **Real-time Video Conferencing**: Connect with multiple participants (up to 5 users per room)
- **Audio Controls**: Easily mute/unmute your microphone
- **Video Controls**: Toggle your camera on/off
- **Camera Selection**: Choose between multiple camera devices
- **Text Chat**: Send and receive messages in the meeting room
- **Room System**: Create or join rooms with custom names
- **User Identification**: Set your nickname for others to identify you

## Technologies Used

- **Frontend**: JavaScript, HTML, CSS
- **Backend**: Node.js, Express
- **Real-time Communication**: WebRTC, Socket.IO
- **View Engine**: Pug
- **Build Tools**: Babel, Nodemon

## Getting Started

### Prerequisites

- Node.js (v12 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/joom.git
   cd joom
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:4000
   ```
